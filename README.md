# 📊 Dashboard Cooperativo - Control de "R"

¡Bienvenido al panel de control de nuestra cooperativa! Este proyecto es un **dashboard interactivo** diseñado para registrar, monitorear y gestionar de forma clara todas las **"R"** estratégicas de nuestra organización.

---

## 🎯 ¿Qué es este proyecto?

Este dashboard centraliza la información clave para llevar un seguimiento transparente de nuestras metas cooperativas. Dependiendo del enfoque de la cooperativa, nos permite medir:

* **Resultados:** Rendimiento financiero, retornos y excedentes.
* **Reservas:** Fondos de reserva legal, educación y previsión social.
* **Rendición de cuentas:** Informes para los socios y asambleas.
* **Responsabilidad Social:** Impacto en la comunidad y sostenibilidad (Reducir, Reutilizar, Reciclar).

---

## 🚀 Características

* **Vista centralizada:** Indicadores clave visuales y fáciles de entender.
* **Acceso rápido:** Disponible en línea para la consulta de socios y directivos.
* **Diseño web ligero:** Desarrollado con tecnologías web estándar (HTML/CSS/JS).
